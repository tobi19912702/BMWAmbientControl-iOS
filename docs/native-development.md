# BMW Ambient Control — native iOS

SwiftUI and CoreBluetooth. Two independent controller profiles: ELK-BLEDOM and MELK-OA21PQ EA. Discover FFF0, validate FFF3 write without response and FFF4 notifications. Only ELK red packet 7E070503FF000010EF has been physically confirmed. Other packets require explicit experimental opt-in. App-played startup scenes are distinct from controller firmware startup behavior. Build unsigned IPA with GitHub Actions; personal signing remains a separate step.
